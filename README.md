# 3D 粒子手势交互系统

这是一个基于 Vue 3 + Vite + Three.js + MediaPipe 的实时 3D 粒子交互项目。通过摄像头捕捉手势（张开手掌/握拳），控制粒子群的扩散与聚合效果。

## 项目介绍

本项目展示了前端 WebGL 技术与 AI 视觉识别的结合。
- **手势识别**：使用 Google MediaPipe Hands 实时检测手部关键点。
- **3D 粒子系统**：使用 Three.js 渲染数千个粒子，支持多种形态变换。
- **交互逻辑**：
  - **握拳/未检测到手势**：粒子聚合为目标形状（如爱心、花朵、土星等）。
  - **张开手掌**：粒子受到斥力向外扩散（爆炸效果）。

## 功能特性

1.  **智能手势识别**：
    - **双倍灵敏**：同时支持双手检测，无需区分左右手。
    - **自由控制**：只要画面中**任意一只手张开**（4指伸展），粒子即刻扩散；全握拳或无手势时自动聚合。
    - **线性强度控制**：扩散力度与手掌张开程度呈 **1:1 线性对应**。
        - **微张**：粒子轻微飘散。
        - **全张**：粒子达到 100% 满额爆发（优化了阈值，自然伸展即可触发满额效果）。
2.  **多模板切换**：
    - 内置 **爱心**、**荷花**（螺旋参数曲面）、**土星**、**佛像**（几何体组合剪影）、**烟花** 等多种 3D 模板。
    - 所有模型均经过算法重构，点阵分布均匀，轮廓清晰美观。
3.  **自定义创作**：
    - **手绘图形**：在弹窗画板中自由绘制，实时生成粒子形状。
    - **图片识别**：上传本地图片，自动识别主体轮廓并生成 3D 粒子（支持自动缩放与边缘提取）。
    - **自动保存**：画板内容自动记忆，方便反复修改。
4.  **自定义颜色**：实时调整粒子颜色。
5.  **响应式设计**：兼容 PC 和移动端 H5 布局。

## 快速开始

本项目提供 **Docker** 和 **本地 npm** 两种启动方式，请根据您的环境选择。

### 方式一：Docker 启动（推荐）

如果您已安装 Docker，可以直接构建并启动容器。

**1. 启动服务**

在项目根目录下执行：

```bash
docker-compose up -d --build
```

**2. 访问项目**

启动完成后，浏览器访问：[http://localhost:3000](http://localhost:3000)

---

### 方式二：本地 npm 启动

如果您希望在本地开发或运行，需要安装 [Node.js](https://nodejs.org/) (推荐 v20+)。

**1. 安装依赖**

```bash
cd frontend
npm install
```

**2. 启动开发服务器**

```bash
npm run dev
```

**4. 访问项目**

开发服务器默认运行在：[http://localhost:3000](http://localhost:3000)

## 注意事项

- **摄像头权限**：由于需要调用摄像头，请确保浏览器允许摄像头权限。
- **HTTPS 要求**：如果在非 localhost 环境下测试（如局域网手机访问），浏览器通常要求在 HTTPS 环境下才能调用摄像头 API。本地开发可以使用 localhost，局域网访问可能需要配置 HTTPS 代理。
